### مقیاس تایپ (Material Type Scale)

| سطح | سایز | وزن | line-height | کاربرد |
|------|------|-----|-------------|--------|
| H1 | `57px` | 700 | `64px` | عنوان صفحه |
| H2 | `48px` | 700 | 1.2 | سربرگ سکشن |
| H3 | `32px` | 700 | 1.25 | عنوان کارت |

**قواعد:**
- عنوان فارسی: Vazirmatn Bold (700)

- letter-spacing: `-0.25px` برای عناوین بزرگ، `0` برای متن

### افکت Glassmorphism (شیشه‌ای)

```css
.glass-surface {
  background: rgba(255, 255, 255, 0.7);
  backdrop-filter: blur(12px);
  -webkit-backdrop-filter: blur(12px);
  border: 1px solid rgba(255, 255, 255, 0.3);
  border-radius: var(--radius-md);
}
```

> در کد موجود، `DashboardFooter` از این افکت استفاده می‌کند: `bg-neutral-darker/70 backdrop-blur-[10px] border border-white/25`.

## 8. لوگو

- **آیکون:** شکل puzzle-piece هندسی (نماد ساختن مسیر ورزشی)
- **Wordmark:** "Gymivo" با Poppins Bold 700، سایز 48px
- **رنگ:** تیره (`#212121`) — **هرگز زرد نکنید لوگو را**

**واریانت‌ها:**
1. افقی: آیکون + wordmark (هدر)
2. فقط آیکون: favicon، اپ آیکون
3. Stacked: آیکون بالای wordmark

**قواعد:**
- حداقل فضای اطراف: 1x ارتفاع آیکون
- حداقل سایز: 24px (آیکون)، 120px (افقی)
- روی زمینه تیره: نسخه سفید
- بدون کشیدن، چرخاندن یا افکت
