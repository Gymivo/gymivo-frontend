# 02 — Brand Voice & Persian Copywriting

**مرجع اصلی:** `bussiness/Gymivo_Brand_Bible_v1.html` + مهارت `gymivo-brand`

---

## 1. هویت برند

| مشخصه | مقدار |
|-------|-------|
| نام | Gymivo (Gym + Evolution) |
| دامنه | gymivo.ir |
| شعار اصلی | **ورزش، ساده‌تر از همیشه** |
| شعارهای فرعی | همراه مسیر ورزشی تو / مسیر رشدت را بساز |

### چشم‌انداز
ورزش را برای همه افراد، در هر مکان و با هر بودجه‌ای، ساده‌تر و در دسترس‌تر کنیم.

### ماموریت
اتصال ورزشکاران، مربیان و تکنولوژی در یک پلتفرم واحد برای مدیریت تمرین، پیشرفت و دستیابی به اهداف ورزشی.

---

## 2. لحن برند

**ویژگی‌ها:** دوستانه، محترمانه، صمیمی، قابل اعتماد

**قاعده طلایی:** از زبان خشک و اداری استفاده نشود.

| ✅ اینطور بنویس | ❌ نه اینطور |
|----------------|-------------|
| «پروفایلت رو تکمیل کن» | «تکمیل پروفایل کاربر الزامی است» |
| «خوش اومدی!» | «ورود موفقیت‌آمیز بود» |
| «هنوز برنامه‌ای نداری» | «برنامه‌ای یافت نشد» |
| «بزن بریم!» | «شروع فرآیند» |

**نکته:** از نیم‌فاصله (‌) به‌درستی استفاده کن: «می‌شود» نه «میشود»، «نمی‌توانید» نه «نمیتوانید».

## 3. شخصیت برند

دوستانه، حرفه‌ای، مدرن، تکنولوژیک، انگیزه‌بخش، قابل اعتماد

- حس پیشرفت

## 4. الگوهای پیام استاندارد

این الگوها را در کل اپ یکدست نگه دار.

### Empty States (حالت خالی)

| سناریو | متن پیشنهادی |
|--------|-------------|
| بدون برنامه فعال | «هنوز برنامه‌ای نداری! برنامه‌ها رو ببین» |
| بدون تمرین امروز | «امروز تمرینی نداری. روز استراحته 😊» |
| بدون مربی | «هنوز مربی نداری. مربی‌ها رو ببین» |

### Success (موفقیت)

| سناریو | متن |
|--------|-----|
| ذخیره پروفایل | «پروفایلت ذخیره شد» |
| ثبت‌نام | «خوش اومدی به جیمیوو!» |
| شروع برنامه | «برنامه‌ات شروع شد. بزن بریم!» |

### Error (خطا)

| سناریو | متن |
|--------|-----|
| ولیدیشن فیلد | «[نام فیلد] الزامی است» |
| نام کاربری تکراری | «این نام کاربری قبلاً گرفته شده» |
| خطای شبکه | «مشکلی پیش اومد. دوباره تلاش کن» |

### Loading

| سناریو | متن |
|--------|-----|
| بارگذاری عمومی | «در حال بارگذاری...» |
| ذخیره | «در حال ذخیره...» |

### Notification (اعلان)

| سناریو | متن |
|--------|-----|
| یادآوری تمرین | «وقت تمرینه! امروز [نام برنامه] داری» |
| تبریک | «آفرین! ۳ روز پشت سر هم تمرین کردی 🔥» |

## 5. قواعد فارسی‌نویسی

1. **نیم‌فاصله:** «می‌کنم»، «نمی‌دانم»، «است» (بعد از ه) → «پروفایل‌ات»
2. **اعداد فارسی:** ۱۲۳۴۵۶۷۸۹۰ نه 1234567890 (در متن کاربر-محور)
3. **علامت‌گذاری:** از «،» و «؟» فارسی استفاده کن
4. **مخفف‌ها:** در صورت لزوم انگلیسی با `dir="ltr"` (مثل `@alireza`)
5. **واحدها:** کیلوگرم (kg)، سانتی‌متر (cm) — واحد می‌تواند لاتین بماند
